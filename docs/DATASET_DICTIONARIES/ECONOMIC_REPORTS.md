# Dataset Dictionary: District Economic Census Reports

## Metadata
- **Canonical ID**: `ECONOMIC_REPORT_COLLECTION`
- **Source / Owner**: Ministry of Statistics and Programme Implementation (MoSPI)
- **Reference Period**: Economic Census 2013-14 Macro Baseline
- **Classification**: `SOURCE_DERIVED`
- **Usable as Direct Local Measurement**: District-level Macro Enterprise Benchmark
