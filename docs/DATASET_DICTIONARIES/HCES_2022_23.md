# Dataset Dictionary: HCES 2022-23 (NSS Report No. 591)

## Metadata
- **Canonical ID**: `HCES_2022_23_REPORT_591`
- **Source / Owner**: MoSPI / NSSO (Ministry of Statistics and Programme Implementation)
- **Reference Period**: August 2022 – July 2023
- **Classification**: `SOURCE_DERIVED`
- **Usable as Direct Local Measurement**: No (Regional / State-level consumption benchmark)

## Fields & Data Dictionary
| Field | Data Type | Unit | Meaning | Provenance | Notes / Limitations |
| ----- | --------- | ---- | ------- | ---------- | ------------------- |
| `state` | String | Categorical | State / UT Name | `SOURCE_DERIVED` | e.g. Maharashtra |
| `sector` | String | Categorical | Rural or Urban sector | `SOURCE_DERIVED` | Survey strata |
| `mpce_without_imputation` | Float | INR / person / month | Monthly Per Capita Expenditure excluding free item imputations | `SOURCE_DERIVED` | Official published survey value |
| `mpce_with_imputation` | Float | INR / person / month | Monthly Per Capita Expenditure including social scheme imputations | `SOURCE_DERIVED` | Includes imputed scheme benefits |
| `food_share_pct` | Float | Percent (%) | Share of MPCE spent on food items | `SOURCE_DERIVED` | State / Sector average |
| `non_food_share_pct` | Float | Percent (%) | Share of MPCE spent on non-food items | `SOURCE_DERIVED` | Services, fuel, transport, clothing |

## Key Caveats & Limitations
1. HCES provides statistical consumption benchmarks at the State and Sector levels. It does NOT provide village-level purchasing power measurements.
2. Questionnaire methodology and recall period structure changed in 2022-23 compared to 2011-12. Time-series comparisons must preserve methodological caveats.
