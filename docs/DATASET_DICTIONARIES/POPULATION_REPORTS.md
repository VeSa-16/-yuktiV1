# Dataset Dictionary: Demographic Population Reports

## Metadata
- **Canonical ID**: `POPULATION_REPORT_COLLECTION`
- **Source / Owner**: Office of the Registrar General & Census Commissioner, India
- **Reference Period**: Census 2011 Reference Table
- **Classification**: `HISTORICAL` / `SOURCE_DERIVED`
- **Usable as Direct Local Measurement**: Official Census historical baseline

## Fields & Data Dictionary
| Field | Data Type | Meaning | Provenance |
| ----- | --------- | ------- | ---------- |
| `district` | String | District Name (e.g. Solapur) | `HISTORICAL` |
| `district_total_population` | Integer | Total Census Population | `HISTORICAL` |
| `rural_population` | Integer | Rural Census Population | `HISTORICAL` |
| `urban_population` | Integer | Urban Census Population | `HISTORICAL` |
| `sex_ratio` | Integer | Females per 1000 Males | `HISTORICAL` |
| `literacy_rate_pct` | Float | Literacy percentage (%) | `HISTORICAL` |
