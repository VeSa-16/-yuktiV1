# SIH Nationals Technical Defense

## Where does the data come from?

From a source registry containing official Indian government datasets, published scheme documents, OSM/Geofabrik geospatial data, WorldPop modelled population surfaces and user-provided evidence. Every metric carries provenance.

## How do you know it is current?

Each source has its own refresh semantics. Daily feeds use short TTLs; monthly reports use monthly expectations; historical Census data is handled as historical reference rather than “stale”.

## What if an API goes down?

Reads are cache-first. The intended path is:

`live → fresh cache → last verified → benchmark/estimate → unavailable`

The UI states which path was used.

## Is AI making the financial decision?

No. Financial arithmetic and scenario propagation live in deterministic, versioned code. AI is limited to classification, grounded explanation, translation and action-plan wording.

## Can you reproduce a score?

Yes, when the score is generated by the implemented deterministic engine: the saved input snapshot, dataset versions, transformation version and calculation/model version form the reproducibility chain.

## Is competitor mapping complete?

No. The platform should explicitly say that OSM/other mapped sources represent observed coverage, not the true universe of businesses.

## What's technically differentiated?

The differentiator is not the LLM by itself. It is the traceable chain:

`local evidence → data quality/provenance → feasibility → financial structure → schemes → what-if → decision trace → execution`

## What cannot be claimed?

- no guaranteed loan/scheme sanction
- no claim of statistical model accuracy without validation
- no claim that mapped competitors are complete
- no claim that modelled population is a census
- no claim that a heuristic confidence value is a calibrated probability
